## 적용

1. delivery_guard.py 추가. 전체 영수증 DB + ACK 전 영수증 + 옛 outbox를 로컬 비교. 본문 원문 URL 정규화와 문자 n-gram 유사도 사용.
2. 옛 outbox는 unverified_outbox로 명시. 실제 전송 증거로 승격하거나 기사 상태를 자동 폐기하지 않음. 모호하면 pending 보존 후 재확인.
3. NewsFormat 발송에 NoveltyReviewFile 필수. 해시로 본문에 결합하고 모든 탐지 match의 비교·새 산업 사실 기록 검증. 동일 확인 본문/불명확한 전송결과는 차단. 진짜 후속보도는 기존 사실 → 새로운 사실 변화 기록으로 허용.
4. 실제 전송 직전에 재검사, 공용 잠금으로 동시 발송 경합 방지. 같은 회차에서 먼저 완료된 영수증도 즉시 비교.
5. 수집기 14일·100건 제한 제거. 영수증 기반 ACK 및 기존 DB 상태는 유지, 뉴스 이력 삭제 없음.
6. 기존 자동화 ai를 40분 간격으로 변경, 알림 선호 유지. 한국시간 07:00 모닝, 07:40·08:20·09:00…22:20·23:00. 하루 25개 슬롯, 모든 인접 슬롯 2,400초 확인.
